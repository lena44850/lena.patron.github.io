# Glisse & Figures — lena.patron.github.io

Un site en français pour découvrir les figures du patinage artistique : sauts, pirouettes, tutoriels vidéo et conseils de sécurité.

## Publication

Le site est conçu pour GitHub Pages. Dans les paramètres du dépôt, activez **Pages** depuis la branche `main` (racine `/`). Il sera ensuite disponible à l’adresse : https://lena44850.github.io/lena.patron.github.io/

## Contenu

- Une vidéo intégrée pour découvrir le saut de valse et un lien vers une playlist de sauts.
- Des cartes de figures avec des liens vers des tutoriels vidéo.
- Un filtre interactif pour afficher les sauts ou les pirouettes.
- Une mise en page responsive et des rappels de sécurité.

Les vidéos et tutoriels externes sont fournis par YouTube. Entraîne-toi sur la glace sous la supervision d’un·e entraîneur·euse.
